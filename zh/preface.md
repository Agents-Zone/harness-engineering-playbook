# 序言

本书是 AgentsZone 社区的集体创作，源自社区成员在 AI 驱动软件工程中的真实实践。

过去两年，AI 编码工具的能力边界持续扩展。多数团队发现了同一个悖论：个人体感更快了，但团队交付效率的提升远没有跟上。与此同时，少数实践者用同样的工具交出了数十倍的成绩——而且是上了生产、经过验证的代码。

差距不在工具，不在 prompt 技巧，而在**工程制度**。

100 倍生产力的团队，都建立了与 AI Agent 结构性特征匹配的工程体系。本书系统性地总结了这套方法论：从规约与验证建立闭环（卷一），到上下文工程与多 Agent 并行实现规模化（卷二），再到混合团队的组织治理（卷三）。

两个核心原则贯穿全书：

- **闭环控制**——明确的规约定义输入，自动化验证检查输出，偏差被即时发现和纠正
- **持续演进**——规约、测试、流程每一层都需要持续改进，否则系统会自我强化地退化

本书面向三类读者：

- **技术决策者**，正在推动团队 AI 转型，需要理解工程基础设施和组织重设计
- **软件工程师**，正在从"自己写代码"转向"指挥 Agent 写代码"，需要完整的转型路径
- **产品人和编程新手**，已经用 Vibe Coding 做出了能跑的产品，需要让它在生产环境中可靠运行

这是一本持续演进的书。每一章都来自社区成员的实战经验，并将随着实践的深入不断更新。
