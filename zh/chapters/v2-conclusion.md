# 卷二回顾：harness 作为独立运转的对齐系统

三章走下来，卷一里的三个诊断都出现了新的形态。意图丢失原来是 spec 没写出来，现在是载体的块之间失去一致性。验证漏了原来是测试没写好，现在是三层机制的某一层失效边界跟实际范围偏了。harness 腐烂原来是文档跟不上代码，现在是 harness 自身暴露出设计时没预见的失效模式。

三个诊断的共同背景一样。执行时人不在每个子空间的现场。这一条物理事实把卷一里由人做的兜底全部拿走了。规约的兜底是人在场随时补 spec，卷二里补不了。验证的兜底是人凭对项目的理解看一眼，卷二里看不过来也判定不了。演进的兜底是人手工发现、归因、修正，卷二里三个动作都爆掉。三个兜底都失效之后，卷一的模式没法照搬。

卷二每一章做的都是同一件事。把卷一里由人承担的责任转到机制。规约章把 spec 从共享工作台改造成意图载体，让载体自己能被多个子空间独立消费。验证章把最后一道人做的裁判改造成失效互补的三层机制，让可信度从机制的组合涌现。演进章把 harness 自身的维护改造成 ISO 9001 双轨制的迁移，让每次异常都成为 harness 改进的输入。三个改造有一个共同点。责任从人转移到机制，但人的判断依然通过共同产出的可判定接口进入循环。

卷二建立的东西可以用一句话概括。这一卷的 harness 是意图对齐的 orchestrator。它把顶层意图切分并分发到多个子空间，验证每个子空间的产出是否忠实于意图，在自身失效时通过双轨制吸收失效为改进。三章合起来定义了一个能在人不在场时独立运转的对齐系统。

规约章讲的是载体应该长什么样以及怎么产出。载体的一条原则是每一次 Agent 消费的单元在注意力承载力内自足承载本单元任务所需的意图。这条原则里的两个变量，单元大小和自足性，互相耦合，只能联合优化。产出这样的载体一个人做不到，体量超出单人的工作记忆和一致性维护能力。共同产出是唯一方法。接口由一条元原则约束。大模型只向人抛回人能判定的决策。判定能力由领域、杠杆、呈现形式三条件定义。

验证章讲的是产出如何在无人裁判的情况下被判定可信。可信来自机制之间失效模式的互补。漂移只在两个地点发生。代码与载体块之间，载体块与载体块之间。三层机制针对两个地点。硬门禁抓结构性，软门禁抓块内语义，集成验证抓跨块假设。三层的失效边界必须显式，因为互补分析的前提是能陈述每层抓什么、放什么。建立三层机制沿用共同产出机制，判定内容从意图变成失效边界。

演进章讲的是 harness 自身也会失效以及怎么处理。验证章的三层机制的前提是载体和验证机制自己是对的，这个前提可能被打破。这类失效验证章的机制抓不到，因为检测机制不能审自己。ISO 9001 的双轨制是这类问题的通用应答。发现要靠人。短期方案不改 harness 让业务不停，长期方案通过共同产出改 harness 自身，把每次失效吸收为 harness 的改进。

三章之间紧密相连。规约章的载体是验证章的锚点，没有清晰的载体，三层机制不知道验证什么。验证章的三层机制是演进章的诊断入口，没有三层机制的失效边界，演进章无法定位问题在哪里。演进章的双轨制是规约章和验证章持续可用的前提，没有演进机制，规约和验证在跑几个月后就开始腐烂。三者构成的循环里，任何一个环节失效整套 harness 都工作不了。

卷二里人依然是执行主体。但人的位置变了。卷一的人是每一步的执行者，卷二的人是判定者、监督者和 harness 演化的驱动者。人依然是意图的唯一来源，抛回给人的可判定决策承载着意图的每一次输入。人依然是 harness 元级别失效的发现者，因为检测者不能审自己。但人不再是执行链条的每一步。执行由 harness 自己承担。

这套体系有一个天然上限。一个人可以主持一个 harness 的建立和演化，做几个关键判定，在必要时启动双轨修复。团队里几个人都在维护自己的 harness 呢？多人协同、跨项目复用、组织层面的 harness 治理，超出了单人可以主持的范围。这属于团队协作模式的新问题，超出了 harness 自身能解决的范围。

卷三的问题是当团队里有多个人都在建立、维护、演化各自的 harness 时，怎么让这些 harness 之间协同、复用、治理。从个人建立一套 harness，到组织沉淀多套 harness 作为长期资产。这个转变的前提是卷二建立的能在人不在场时独立运转的 harness。没有单人版本的成熟机制，团队级别的协作是无源之水。放大的前提是本身站得住。
