# 卷三：治理百倍速的组织

卷一和卷二解决的是工程师和 Agent 之间的问题。卷三要解决的是人和人之间的问题：当多个人类各自指挥 Agent 军团，组织架构、角色分工、流程节奏都需要重新设计。

这部分内容目前仍在研究中。我们在 30 多个组织级转型案例中观察到了一些共性模式，但还没有足够的信心将它们固化为通用方法论。每个组织的上下文差异太大，过早发布不负责任。

目前有一份内部预览版，包含我们对以下问题的阶段性思考：

- 传统团队结构为什么在 Agent 时代失效
- 瓶颈从代码转移到组织后，哪些角色需要重新定义
- 流程如何匹配 Agent 的速度
- Conway 定律在 Agent 时代的新含义

如果你的团队正在经历类似的转型，欢迎联系马驰交流，获取预览版内容。我们也在寻找更多愿意分享转型经验的团队。你的案例会让这本书更完整。
