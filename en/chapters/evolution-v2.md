# Evolution: From Manual Inspection to Automated Drift Detection

> Pending interviews.

**Core question this chapter answers:** When I'm not watching, who detects drift between specs and code?

**Reader state entering:** Multiple Agents are running in parallel, and you're no longer monitoring in real time. Then you discover the human-in-the-loop maintenance approach has broken down.

**Reader state leaving:** Has established automated drift detection mechanisms. The system can self-monitor without human presence.

**Nature of this evolution:** The developer is no longer in the loop. Human-in-the-loop maintenance has failed. This is fundamentally a monitoring and self-healing problem — automated mechanisms are needed to detect drift between the system and code.
